# Exemplos de conversa

Frases para exercitar o assistente depois de subir o ambiente ([Docker](execucao-docker.md) ou [UV](execucao-local-uv.md)).

## Fluxo completo (conta + cartão)

```text
Quero abrir uma conta
Meu nome é Levina Passos
Meu CPF é 38888206850
Quero um cartão de crédito, meu CPF é 38888206850
meu cpf é 388.882.068-50 me de os detalhes do cartao
```

## Frases para testar o roteador

**Cartão de crédito**

- quero um cartao
- preciso de um cartao de credito
- me mostra opcoes de cartao
- quero saber sobre cartao platinum
- como funciona cartao de credito

**Abrir conta**

- quero abrir uma conta
- preciso criar uma conta bancaria
- como faço para ter uma conta
- abrir conta no banco
- criar conta nova

Tipos de cartão disponíveis: `platinum`, `gold`, `silver` e `mdzao`. O cartão exige conta pré-existente.
